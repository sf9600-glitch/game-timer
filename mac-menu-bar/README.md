# 遊戲計時器 — Mac 選單列版

在 Mac **選單列**（螢幕右上角）顯示**已完成計時器**，資料來自雲端同步（與網頁版相同帳號）。

## 功能

- 選單列圖示：有已完成項目時顯示 `⏱數量`
- 列表顯示：角色 · 任務、已完成多久
- 每 60 秒自動從雲端更新
- 可開啟網頁版、登入／登出

## 需求

- Mac（macOS 13 Ventura 或以上）
- 已安裝 **Xcode** 或 **Xcode Command Line Tools**
- 網頁版已用 **同一組雲端帳號** 登入並同步過

## 安裝步驟

1. 打開 **終端機**
2. 執行：

```bash
cd "mac-menu-bar 資料夾的完整路徑"
bash scripts/build.sh
```

3. 完成後到 `mac-menu-bar/dist/遊戲計時器選單列.app`
4. **雙擊** 執行（若被擋，右鍵 → 打開）
5. 可拖到 **應用程式** 資料夾，開機後手動再開一次

## 第一次使用

1. 點選單列的 **計時器圖示**
2. 輸入與網頁版相同的 **Email / 密碼**
3. 按 **登入雲端**
4. 下方會列出「已完成」計時器

## 注意

- 必須在 **網頁版登入雲端並同步**，選單列才有資料
- 只顯示**尚未清除**的已完成計時器（與網頁版邏輯相同）
- 此 App **不會**出現在 Dock（僅選單列），屬正常現象

## 疑難排解

| 狀況 | 做法 |
|------|------|
| 編譯失敗 | 終端機執行 `xcode-select --install` 安裝工具 |
| 無法打開 App | 右鍵 App → 打開 → 仍要打開 |
| 登入後是空的 | 確認網頁版已登入同一帳號，且雲端狀態為「已同步」 |
| 資料不更新 | 點選單內 **↻** 手動刷新 |

## 資料夾說明

- `Sources/GameTimerMenuBar/` — 程式原始碼
- `scripts/build.sh` — 一鍵編譯腳本
- `dist/` — 編譯後的 `.app`（執行 build 後產生）
