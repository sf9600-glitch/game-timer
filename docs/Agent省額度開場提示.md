# Agent 省額度開場提示（複製貼上）

> **已啟用自動規則**：專案內 `.cursor/rules/agent-quota-and-user.mdc` 會讓 Agent **每次自動**遵循下列方式，一般**不必再手動貼**精簡版。若某次對話沒照做，可再貼一次精簡版提醒。

每次開 **新 Agent 對話**時，也可把下面「精簡版」貼在第一則訊息**最前面**（可選），再接你的需求與截圖。

---

## 精簡版（建議每次貼上）

```
【工作方式】
- 我不懂程式，請用繁體中文、白話說明；改完用三句話告訴我：改了什麼、要存哪幾個檔、怎樣算成功。
- 只改與本次需求有關的檔，不要重構整個專案，不要順便改無關功能。
- 專案已拆分：index.html（結構）、css/app.css（樣式）、js/app.js（邏輯與 Supabase 設定）。優先改 css/js，除非必須才動 index.html。
- 上線：存 index.html / css/app.css / js/app.js 會自動 push；網址 https://sf9600-glitch.github.io/game-timer/ 。若只改樣式，結尾提醒 Cmd+S 與 Cmd+Shift+R。
- 同一問題請一次改完；若需我確認，最多問一個關鍵選擇題，不要長篇教學。

【本次需求】
（在這裡寫你要什麼，並附截圖）
```

## 線上沒變化時（先自己做，再問 Agent）

1. Cmd+S 存 `css/app.css` 或 `js/app.js`（有改哪個存哪個）
2. 等 1～3 分鐘
3. 開 https://sf9600-glitch.github.io/game-timer/ → **Cmd+Shift+R** 強制重新整理

仍不對，再把 Network 是否 200、截圖貼給 Agent。
