# 背景推播（App 關閉也能收到）

計時到 0 時由 **Supabase 伺服器**在預定時間發送 Web Push。需完成下列設定（約 15–30 分鐘）。

## 條件

- iPhone：**Safari → 加入主畫面**，從圖示開啟，iOS **16.4+**
- 已 **登入雲端帳號**（推播排程綁定帳號）
- 已按「允許通知」
- 已在 `js/app.js` 填入 **VAPID 公鑰**

---

## 1. 產生 VAPID 金鑰

在電腦終端機執行：

```bash
npx web-push generate-vapid-keys
```

會得到 **publicKey** 與 **privateKey**。

- **publicKey** → 貼到 `js/app.js` 的 `WEB_PUSH_VAPID_PUBLIC_KEY`
- **privateKey** → 只放在 Supabase（見步驟 3），不要寫進 GitHub

---

## 2. 資料庫

Supabase → **SQL Editor** → 執行：

1. `supabase/schema.sql`（若尚未執行）
2. `supabase/push-schema.sql`

---

## 3. 部署 Edge Function `dispatch-push`

安裝 [Supabase CLI](https://supabase.com/docs/guides/cli)，在專案資料夾：

```bash
supabase login
supabase link --project-ref 你的專案-ref
supabase secrets set VAPID_PUBLIC_KEY="公鑰"
supabase secrets set VAPID_PRIVATE_KEY="私鑰"
supabase secrets set VAPID_SUBJECT="mailto:你的Email"
supabase secrets set CRON_SECRET="自訂一組長密碼"
supabase functions deploy dispatch-push --no-verify-jwt
```

`SUPABASE_URL` 與 `SUPABASE_SERVICE_ROLE_KEY` 通常會自動帶入；若沒有，到 Dashboard → Settings → API 複製 **service_role** 設為 secret。

---

## 4. 每分鐘自動發送（排程）

在 Supabase Dashboard → **Edge Functions** → `dispatch-push` → **Schedules**（或 Cron）：

- 頻率：`** * * * *`（每分鐘）
- HTTP Header：`x-cron-secret: 你設的 CRON_SECRET`

若沒有 Schedules，可用 [cron-job.org](https://cron-job.org) 每分鐘 POST：

`https://你的專案.supabase.co/functions/v1/dispatch-push`

Header：`x-cron-secret: 你的密碼`

---

## 5. 驗證

1. 存檔部署網頁，`WEB_PUSH_VAPID_PUBLIC_KEY` 已填
2. 手機從主畫面開啟 → 登入雲端 → 允許通知
3. 開一個 **1 分鐘**計時（勾選到點通知）
4. **完全關閉 App**，等 1 分鐘後應收到通知

---

## 說明

- 未登入雲端：只有 App 開著時的前台通知，**沒有**背景推播
- 誤差：排程每分鐘檢查一次，可能晚 **0–60 秒**
- 免費額度：小團使用通常足夠；詳見 Supabase 用量
