# 文字列表版面：給 AI 的提示詞範本

> 適用專案：遊戲計時器 `index.html` · 顯示模式「文字列表」  
> 目的：快速做出「任務｜時間｜×」靠左排列、時間欄垂直對齊的效果（含 Safari）

---

## 建議的提示詞模板（直接複製改字）

```
文字列表模式，每一列版面：

[角色+任務] | [倒數+日期] | [×]

要求：
1. 時間區塊緊貼任務文字右側（中間不要有大片空白）
2. 倒數與日期在時間欄內靠左對齊
3. 同一列表內，各列的「時間欄」左緣要垂直對齊
4. × 按鈕在時間右側，不要推到列的最右邊
5. 我在 Safari，請避免 subgrid / 固定右欄把內容推到最右
```

有截圖時，加一句：

```
附圖：圖一是錯的（只有時間在最右），圖二是對的（要有角色任務）。
我要的是圖二任務 + 圖一時間，排在一起靠左。
```

---

## 為什麼這樣寫比較快

| 容易誤解的說法 | 較清楚的說法 |
|----------------|--------------|
| 「時間靠左」 | 「時間欄在任務右邊、欄內文字左對齊」 |
| 「跟其他的對齊」 | 「同一帳號列表內，各列時間欄左緣同一條垂直線」 |
| 「× 也靠左」 | 「× 在時間右側，不要用 margin-left: auto 推到列尾」 |

「靠左」在 UI 裡可能指三種不同意思，分開寫就不容易來回改。

---

## 可選補充（有就更快）

- **模式**：簡潔 / 彩色 / **文字列表**
- **瀏覽器**：Safari（若和 Chrome 不同）
- **參考**：「像 Excel 三欄：A 任務、B 時間、C 刪除，都靠左排」

---

## 一句話極簡版

> 文字列表：任務｜時間（欄內左對齊、各列時間欄垂直對齊）｜×，三塊緊挨靠左，× 不要在最右；Safari。

照這個結構描述，通常一兩輪就能對齊目標效果。
